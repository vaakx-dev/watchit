# MetaHub images

- Source: https://www.metahub.space/
- Terms: https://www.metahub.space/terms
- Posters and backgrounds: https://images.metahub.space/
- Episode thumbnails: https://episodes.metahub.space/

Cinemeta supplies image URLs. Episode thumbnail requests can redirect to `https://image.tmdb.org/t/p/w780/`. The app validates each redirect, caches approved raster images locally, and retains source URLs and retrieval times in its attribution archive.

MetaHub's API terms do not grant rights to the associated images. Missing author and license information remains unspecified. HTTP cache headers are not a copyright license.
