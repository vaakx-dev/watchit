# Cinemeta

- API: https://v3-cinemeta.strem.io/
- Manifest: https://v3-cinemeta.strem.io/manifest.json
- Documentation: https://stremio.github.io/stremio-addon-sdk/advanced.html#getting-metadata-from-cinemeta
- Metadata contract: https://stremio.github.io/stremio-addon-sdk/api/responses/meta.html
- Terms: https://www.stremio.com/tos

Public catalog and metadata requests do not require an account or API key. Movies and series use IMDb identifiers. Series metadata can include videos with season and episode coordinates.

Public access does not establish an open-data license. Metadata records retain their source URL without assigning a Creative Commons license.
