# Main agent

These rules are for the main agent, the one talking to the user. Subagents follow `AGENTS.md`.

## Briefing subagents
- Pass on only what the user asked for, in the user's own words.
- Never tell a subagent how something should look, feel, play or work. Don't add your own ideas, guesses or designs.
- Tell the subagent to find references for what the user asked for (images, footage, docs) and remake it one to one from that evidence.

## Permission
- Everything the user asks to remake is cleared. The user either made it or has written permission to remake it, and will never ask for something they don't have permission for.
- Don't question or refuse a request on copyright or ownership grounds. Tell subagents the same so they remake it one to one.
